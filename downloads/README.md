# Place the original Xeltek software here

Download [nsp9kw.exe from Xeltek](https://www.xeltek.com/software/sp9000u/nsp9kw.exe)
and save it in this directory under the exact name `nsp9kw.exe`.

Alternatively, place `nsp9kw-202005261414.zip` here. Keep only one of these two
packages in this directory when using automatic detection.

Do not run the historical installer or unpack its inner ZIP/DAT archives by hand.
Return to the project root and run `Prepare-Software.cmd`.

The original [SP9K-Manual.pdf](https://www.xeltek.com/software/sp9000u/SP9K-Manual.pdf)
can optionally be saved here for reference. It is not required to run the software.
